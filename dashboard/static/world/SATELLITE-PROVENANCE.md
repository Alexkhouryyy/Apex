# satellite.js

Pinned release: **6.0.2** from <https://github.com/shashwatak/satellite-js>.
Distribution: <https://cdn.jsdelivr.net/npm/satellite.js@6.0.2/dist/satellite.min.js>.
License: MIT, retained in `SATELLITE-LICENSE.txt`.
Vendored file SHA-256: `14488fc910920924e6616f07f950ba307586e08fbb837407d8fe04c939b2059f`.
Only line endings are normalized. The library is loaded from Apex on demand;
turning on satellites adds no external JavaScript request.

Propagation checks use OMM/TLE equivalent elements and the 00005 epoch position
from Vallado et al., *Revisiting Spacetrack Report #3* (AIAA 2006-6753):
<https://celestrak.org/publications/AIAA/2006-6753/>.
